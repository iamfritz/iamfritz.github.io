# Personal Portfolio — GitHub Pages

A responsive, single-page developer portfolio built with HTML, CSS, and vanilla JavaScript.

## Before publishing
1. Open `index.html`.
2. Replace `Fritz` if you want a different display name.
3. Replace `YOUR_EMAIL@example.com` with your public contact email.
4. Replace `YOUR_GITHUB_USERNAME` and `YOUR_LINKEDIN` with your profile URLs.
5. Replace the representative project descriptions with real projects. Add project links or screenshots if available.

## Publish at `https://YOUR_GITHUB_USERNAME.github.io`
1. Create a GitHub repository named exactly `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to deploy. Your site will be available at `https://YOUR_GITHUB_USERNAME.github.io`.

No build step or npm installation is required.
